# UniFlow 

UniFlow is a student productivity workspace designed to help university students manage their academic life in one place.

##  Features

-  Course management
-  Course progress tracking
-  Task management
-  Weekly timetable
-  Persistent data using localStorage
-  Responsive interface
-  Student-focused dashboard

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

##  Current Version

### V1 — Frontend

The current version of UniFlow is a frontend-focused application built with HTML, CSS and JavaScript.

Data is currently stored locally using browser localStorage.

##  Future Development

UniFlow is planned to evolve alongside my learning journey.

Future versions may include:

- Backend API
- Database integration
- User authentication
- Cloud deployment
- Docker
- CI/CD
- Notifications
- Cloud-based data synchronization
